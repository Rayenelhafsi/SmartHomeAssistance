# User Stories for Smart Home Assistance Application

## User Authentication
1. As a user, I want to log in to the application using my email and password so that I can access my home settings.
2. As a user, I want to log in using my Google account so that I can quickly access the app without creating a new account.
3. As a user, I want to log out of the application so that my account remains secure.

## Home Screen
4. As a user, I want to see a personalized greeting on the home screen so that I feel welcomed.
5. As a user, I want to view my house name on the home screen so that I can easily identify my home.
6. As a user, I want to see a profile picture on the home screen so that I can recognize my account.

## Room Management
7. As a user, I want to view a list of rooms in my house so that I can manage them effectively.
8. As a user, I want to add new rooms to my house so that I can expand my smart home setup.
9. As a user, I want to remove rooms from my house so that I can keep my setup organized.
10. As a user, I want to view details about each room, including the number of devices, so that I can manage my smart devices effectively.

## Device Management
11. As a user, I want to control devices in each room so that I can manage my smart home environment.
12. As a user, I want to receive notifications about device status changes so that I am informed about my home.

## Settings
13. As a user, I want to access the settings screen to modify my account information, such as my name and profile picture.
14. As a user, I want to change my password for security purposes.
15. As a user, I want to configure notification preferences so that I can choose how I receive updates.

## Notifications
16. As a user, I want to receive notifications about important updates related to my home configuration so that I am informed.
17. As a user, I want to receive alerts for any unusual activity detected in my home.

## User Management
18. As a user, I want to view a list of all users associated with my home so that I can manage access.
19. As a user, I want to add new users to my home so that they can also access the smart home features.
20. As a user, I want to remove users from my home so that I can control who has access.
